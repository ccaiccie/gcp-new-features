# GCP new features — Terraform practice labs

Companion Terraform labs for the [GCP new features](https://www.youtube.com/playlist?list=PLMJ6gO8q8Y0k) YouTube playlist from the Network Technician channel.

Each video has its own folder. Copy `terraform.tfvars.example` to `terraform.tfvars`, fill in your project IDs, then run `terraform init`, `terraform plan`, and `terraform apply` from that folder. Destroy the lab when you are finished.
